STRUCT_0 is not defined

Load a structure and use the exact STRUCT_N name shown in the shell's structure list. IDs need not be consecutive. These variables exist only in the app's shell.

The viewport is not updating

Select the structure with studio.show(atoms). During a long run, call studio.update(atoms) or attach it to the optimizer as shown in section 1. Without that call, changes appear when the run finishes successfully. An already relaxed structure may barely move.

A package or model will not load

For ModuleNotFoundError, check the selected environment in Manage Packages, install the missing package, and click Restart Python. Use Check Dependencies for package conflicts. For a 401/403 model-download error, check model access, login, and the Hugging Face paths in section 2.

The calculator or structure is rejected

Energy and force calculations need an attached calculator that supports your material. For structure errors, read the named STRUCT_N in Output; positions must be finite and per-atom arrays must match the atom count. Use studio.add(atoms) to register a new object before calling studio.update.

Stop, restart, or restore

Stop keeps the last accepted geometry; a blocked worker is restarted. Errors discard unpublished structure edits.

Restart Python clears variables and calculators while retaining current geometry and editor text. Structure → Reset to Original restores the active structure from its original input using the current replication settings.
