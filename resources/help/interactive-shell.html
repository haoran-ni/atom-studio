Load a structure, then open Code → Open Interactive Shell. Enter Python in the editor and click Run or press Command/Ctrl+Enter. Run executes the whole editor; replace the previous example before trying another.

STRUCT_NYour loaded structures as ASE Atoms objects.
studioHelpers for updating and selecting viewport structures.

These names need no import. Import other modules and calculators as needed. Variables and attached calculators persist between runs.

Use a loaded structure

Replace N with the ID shown in the shell's structure list: STRUCT_0, STRUCT_1, and so on. IDs stay with their documents; switching the viewport does not rename them.

atoms = STRUCT_0
print(atoms.get_chemical_formula())
print(atoms.positions)
print(np.mean(atoms.positions, axis=0))

atoms refers to the same object as STRUCT_0, so editing either changes that structure. Use print(...) to see values in Output.

Update the viewport

Changes to loaded structures appear automatically after a successful Run. Positions and cell lengths are in angstroms.

STRUCT_0.positions[:, 2] += 0.5

To show an intermediate change during a running script, call studio.update(atoms). Use studio.show(atoms) to select its document.

atoms = STRUCT_0
studio.show(atoms)
atoms.positions[:, 2] += 0.1
studio.update(atoms)

For a separate copy to experiment on:

trial = studio.add(STRUCT_0.copy())
studio.show(trial)

Watch a relaxation live

Attach studio.update to an ASE optimizer to show each step. This complete example uses EMT for a loaded copper structure; replace the calculator with one suitable for your material. It relaxes atom positions with a fixed cell.

from ase.calculators.emt import EMT
from ase.optimize import BFGS

atoms = STRUCT_0
studio.show(atoms)
atoms.calc = EMT()

optimizer = BFGS(atoms, logfile="-")
optimizer.attach(studio.update, interval=1, atoms=atoms)
converged = optimizer.run(fmax=0.05, steps=100)
print("Converged:", converged)

fmax=0.05 sets the force threshold in eV/Å; steps=100 limits the number of steps. Check convergence in Output. Live updates/s limits preview frequency; the final successful geometry is always applied.

Stop interrupts a calculation and keeps the last accepted geometry. Save reusable code with Save .py and save geometry with Files → Export Structures.
