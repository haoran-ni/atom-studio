Install packages or switch environments

Open Code → Manage Packages. Enter a package name and click Install / Upgrade. The MACE and UMA / FAIRChem shortcuts select mace-torch and fairchem-core. Packages marked Bundled (read-only) come with the app.

Use New… to create a separate package set, then choose it from the Environment dropdown. Switching or installing clears Python variables and calculators; loaded geometry and editor text are retained.

External Conda / venv environments cannot be selected directly. Create an app-managed environment and install compatible project requirements into it. Launching the app from an activated terminal does not change its Python interpreter.

Use the environment in your own terminal

Copy the environment path shown in Manage Packages after preparation finishes. Replace the example path below with it. These commands belong in your terminal, not the app's Python editor.

macOS / Linux · zsh or bash

source "/path/to/environment/bin/activate"
unset PYTHONHOME PYTHONPATH __PYVENV_LAUNCHER__

For fish, use source "/path/to/environment/bin/activate.fish".

Windows · PowerShell

& "C:\path\to\environment\Scripts\Activate.ps1"

If activation is blocked, use Command Prompt:

call "C:\path\to\environment\Scripts\activate.bat"

Then verify the interpreter and use pip:

python -c "import sys; print(sys.executable)"
python -m pip install PACKAGE
python -m pip check

Stop calculations before changing packages externally. Afterward, click Restart Python in the shell and Refresh in Manage Packages. Run deactivate to leave the environment. A terminal shares the installed packages, but does not have the app's live STRUCT_N or studio objects.

Helpful paths

Run this in the app's Python shell:

import sys
from pathlib import Path

print("Environment:", sys.prefix)
print("Python:", sys.executable)
print("Bundled runtime:", sys.base_prefix)
print("Working directory:", Path.cwd())

Manage Packages shows the writable environment folder. Working directory… chooses where relative output files are saved. The bundled runtime is read-only. If you move the app, reopen Manage Packages to repair its environment links.

Hugging Face login for UMA

Install fairchem-core and obtain access to the model on Hugging Face. To find the app's credential and cache paths, run this in the Python shell:

from huggingface_hub import constants
print(constants.HF_HOME)
print(constants.HF_TOKEN_PATH)
print(constants.HF_HUB_CACHE)

In your activated terminal, set HF_HOME, HF_TOKEN_PATH, and HF_HUB_CACHE to those printed paths, then run hf auth login. For example, zsh/bash uses export HF_HOME="/printed/path"; PowerShell uses $env:HF_HOME = "C:\printed\path".

Restart the app's Python shell after login. Activation alone does not align cache paths. Keep tokens out of saved scripts.
